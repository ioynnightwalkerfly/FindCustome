# Project Summary - FindCustome

## Project Overview
A web-based customer search and management system. It allows users to search for customer names and see their corresponding book page numbers. It also features a management panel for adding, editing, and deleting customer data, with local storage persistence and backup capabilities.

## Current State
- `index.html`: Main application file containing HTML, Tailwind CSS, and JavaScript logic.
- `icon.png`: Application icon.
- `PROJECT_SUMMARY.md`: This file.

## Technical Decisions
- **Styling**: Tailwind CSS via CDN.
- **Data Persistence**: `localStorage` in the browser.
- **Icons**: Font Awesome for UI icons.
- **Typography**: Sarabun (Google Fonts) for Thai language support.
